# Vietnam

A photography diary by Bedasree Samaddar, arranged in five chapters: Hanoi, Ninh Binh, Sapa, Da Nang, and Hoi An.

Static HTML, CSS, and JavaScript; no runtime dependencies. Hosted with GitHub Pages from the root of `main`.

To preview locally, run `python3 -m http.server 8000` and open http://localhost:8000.

The `assets` folder contains optimized WebP copies with metadata removed. Original photographs remain local and are excluded from Git. To regenerate the site after adding originals, install Pillow and run `python3 scripts/build.py`.
